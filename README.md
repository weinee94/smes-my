# SMEs.MY

SMEs.MY focuses on a specific Malaysian small-business problem: marketing brings customer enquiries, but the team does not reliably answer, own and follow them up. Current direction and boundaries are in [SMES_MY_POSITIONING.md](SMES_MY_POSITIONING.md); current verification is in [PROJECT_STATUS.md](PROJECT_STATUS.md).

Public routes: homepage, /weineetan, /blog and /contact. The contact route links to a focused Google Form; its responses go to a private Google Sheet with Gmail notifications and manual lead tracking. See [docs/TALENT_INTAKE_OPERATIONS.md](docs/TALENT_INTAKE_OPERATIONS.md). The old Accounting／Company Secretary lead backend remains in the repository for historical records, but the old request routes and Project Brief Generator are no longer published.

Run `npm test`, `npm run lint` and `npm run build` before deployment. GitHub main deploys to Vercel.
