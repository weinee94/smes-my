# SMEs.my

Independent landing page and directory starter for `smes.my`.

## Domains

- Public marketplace brand: `smes.my`
- Corporate email identity: `smes.com.my`

## Deploy on Vercel

1. Create a GitHub repository and push this folder.
2. In Vercel, choose **Add New Project** and import the GitHub repository.
3. Use the default static project settings. No build command is required.
4. Add both domains in Vercel:
   - `smes.my`
   - `www.smes.my`
5. Keep email DNS records for `smes.com.my` separate from this site unless you want a corporate website there later.

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static file server.
