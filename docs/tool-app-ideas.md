# SMEs.MY Tool App Ideas

Internal notes for possible future apps. These ideas should not be published on `smes.my` until they
can provide real user value, have a clear cost model, and fit the directory platform.

## Principle

Do not add weak free tools to the public directory just to fill pages. A tool should become a
separate app, gated workflow, or paid feature only when it solves a real SME job and has a practical
usage/cost model.

## Idea: WhatsApp Enquiry To Sales Brief

Original pain:

- Malaysian SME owners receive messy enquiries through WhatsApp, Facebook ads, comments, DMs, and
  voice notes.
- The owner often needs to reply quickly, ask the right quote-before-price questions, and avoid
  losing the lead.
- A useful product would turn messy customer input into a practical sales brief and suggested reply.

Potential app shape:

- Standalone mini app, not a public directory filler section.
- Login or access-code gated before AI usage.
- Possible usage model: bring-your-own API key, paid credits, or internal owner-only workflow.
- Output should be generated by AI, not a shallow rule-based template.
- The UI should feel like a workbench: inbox input, extracted details, missing quote fields, reply
  drafts, saved leads, and follow-up status.

Useful output sections:

- Quote readiness: ready to quote, almost ready, needs details, or too vague.
- Customer needs summary: product/service, quantity/scope, location, timeline, budget, special
  requirements, contact clue.
- Missing quote questions: only the few details needed before pricing.
- Suggested WhatsApp reply: directly copyable, friendly, and localized for Malaysian SME context.
- Next action: save lead, request missing info, prepare options, follow up.

Important constraints:

- Do not spend SMEs.MY tokens for anonymous public visitors.
- Do not expose API keys in frontend code.
- Do not publish until the output is clearly better than manually using ChatGPT.
- Consider collecting real examples from SME owners first, then design the app around repeated
  patterns.

Future validation ideas:

- Interview SME owners who handle WhatsApp leads daily.
- Collect 20-30 anonymized real enquiry samples.
- Test whether AI output saves time or improves reply quality.
- Check willingness to pay: monthly fee, per-credit, or BYO API key.
- Decide whether this belongs under SMEs.MY, a separate product, or provider-side CRM tooling.
